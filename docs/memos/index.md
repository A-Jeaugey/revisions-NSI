# 🧰 Mémos transverses

Quatre mémos compacts à garder ouverts pendant les révisions et à imprimer à J-3.

<div class="grid cards" markdown>

- :material-chart-line: **Complexités**

    Tableau des complexités O(...) de **tous** les algorithmes du programme.

    [→ Ouvrir le mémo](memo_complexites.md)

- :material-language-python: **Pièges Python (bac)**

    Mutabilité, slicing, compréhensions, dictionnaires, exceptions, modules

    [→ Ouvrir le mémo](memo_python_bac.md)

- :material-database-outline: **Cheat-sheet SQL**

    Anatomie d'un SELECT, WHERE/HAVING, GROUP BY, JOIN (INNER/LEFT), ACID,

    [→ Ouvrir le mémo](memo_sql_bac.md)

- :material-book-alphabet: **Glossaire alphabétique**

    Définitions courtes et formelles de tous les termes NSI Terminale, classés
    de A à Z. Indispensable pour la veille du bac.

    [→ Ouvrir le mémo](memo_vocabulaire.md)

</div>
