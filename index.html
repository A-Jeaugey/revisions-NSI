    • Première fois ici ?

      Lis d'abord le plan de révision (4 semaines structurées), puis pioche dans les fiches selon ton avancement.

      Toutes les fiches sont indexées par numéro de séquence (0 → 80). Chacune contient TL;DR, vocabulaire, code Python, diagrammes, pièges et Q/R bac.

    ⚙️ Comment utiliser ce site⚓

    Mobile-friendly

    Le site fonctionne aussi bien sur ordinateur que sur téléphone — révise dans le train, dans la queue à la cantine ou avant de t'endormir.

    Recherche full-text

    Tape ou / pour ouvrir la barre de recherche. Tape un mot (ex : « Hanoï », « JOIN », « BFS ») et tu trouveras toutes les occurrences.

    Mode sombre

    Bascule clair/sombre via l'icône en haut à droite.

    Code copiable

    Sur chaque bloc de code Python, le bouton copie le contenu en un clic.
